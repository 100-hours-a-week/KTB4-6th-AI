# ADR-0013: Nemotron3 Diarization으로 화자 구간을 나눈 후 Qwen3-ASR으로 전사한다

## Status

Accepted

---

## Context

Meety는 한국어 다자간 회의가 진행되는 동안 전사 텍스트, 발언의 시작·종료 시각, 화자 라벨을 함께 제공해야 한다.

음성 파이프라인을 구현하기 위해 ASR과 화자분리에 어떤 모델을 어떤 순서로 실행하고, 두 결과를 어떻게 연결할지 결정해야 한다. 한국어 회의 성능과 발화 종료 후 지연을 만족하면서 여러 회의를 동시에 처리할 수 있는 구조가 필요하다.

이 문서는 음성 분할과 전사·화자 결합 방식을 결정한다. Modal 서빙 방식과 모델별 GPU 배치 정책은 별도 결정으로 둔다.

## Decision Drivers

- **발화 구간 종료 후 결과를 빠르게 제공해야 한다.** 각 발화 구간 종료부터 전사·시각·화자 결과를 수신하기까지 p95 10초 이내를 목표로 한다. 모델 추론 시간뿐 아니라 구간 종료 대기, 처리 대기열, 결과 전달 시간을 포함한다.
- **한국어 회의를 정확하게 전사해야 한다.** 한국어 기술 회의의 발언과 용어를 인식해야 한다. 실제 회의 음성과 정답을 이용한 결과를 선택 근거로 삼는다.
- **여러 회의를 동시에 처리할 수 있어야 한다.** 여러 회의를 처리할 때도 지연 목표를 유지하고, GPU 자원을 효율적으로 사용해야 한다.
- **전사와 화자분리 결과를 함께 제공해야 한다.** 텍스트, 시각, 화자 라벨이 연결된 결과를 제공해야 한다. 별도 정렬과 결과 수정이 필요한 부담도 고려한다.

---

## Considered Options

### 1. Qwen3-ASR streaming + ForcedAligner + Nemotron-3

Qwen3-ASR 스트리밍 전사를 ForcedAligner로 정렬하고, Nemotron 화자 활동과 겹치는 시각을 이용해 화자를 연결한다. Qwen 스트리밍은 timestamp를 반환하지 않아 ForcedAligner를 사용한 별도 정렬이 필요하다.

**성능과 화자 연결 문제**

A10 한 대에서 한국어 특화 Qwen `TeamUNIVA/qwen3_asr_1.7b_ko`, Qwen3-ForcedAligner-0.6B, Nemotron-3를 실행하고 2초마다 누적 음성과 전사를 정렬한 결과다.

| 항목 | 결과 | 의미 |
| --- | ---: | --- |
| 전사 CER 진단값 | 22.07% | 전사 텍스트 자체의 오류 |
| ASR 갱신 지연 p95 | 0.46초 | 2초 입력 청크 수집 후 ASR 갱신까지 |
| 길이 0인 최종 정렬 단위 | 73 / 602개, 12.13% | 시작·종료 시각이 같아 발음 위치를 시간 구간으로 표현하지 못함 |
| 시각을 부여하지 못한 어절 | 78 / 472개, 16.53% | 경계 길이 0인 어절 62개, 비정상적으로 긴 정렬이 포함된 어절 16개 |
| 최종 시각이 연결된 출력 문자 | 81.97% | 약 18%의 문자는 최종 시각도 연결되지 않음 |
| 최종 화자가 연결된 출력 문자 | 76.48% | 약 24%의 문자는 최종 화자도 연결되지 않음 |
| 조기 화자 포함 출력 지연 p95 | 9.50초 | 어절 종료 추정 시각→조기 화자 포함 출력 |
| 조기 화자 포함 결과가 덮는 출력 문자 | 60.16% | 조기에 화자를 붙여 제공할 수 있는 범위가 전체 출력의 약 60% |
| 최종 시각 확정 지연 p95 | 27.74초 | 어절 종료 추정 시각→해당 구간의 최종 결과 |
| 조기 안정 결과가 최종 단계에서 바뀐 비율 | 27 / 333개, 8.11% | 앞서 제공한 텍스트·시각·화자를 다시 수정해야 하는 경우 |

핵심 문제는 **전사는 빨리 나와도 그 전사를 음성의 어느 시각에 놓을지 결정하지 못해 화자분리와 연결할 수 없다는 것**이다. 예를 들어 어절의 시작과 끝이 같은 시각으로 정렬되면, 그 어절이 Nemotron의 어느 화자 활동 구간과 겹치는지 판단할 근거가 사라진다. 이 경로에서는 정렬 실패 때문에 78개 어절의 화자 연결이 막혔고, 활동량 부족·겹친 발화 등의 이유로 추가 29개 어절도 화자를 붙이지 못했다.

따라서 ASR 갱신 p95 0.46초만으로 저지연 요구를 충족한다고 볼 수 없다. 조기 화자 포함 결과는 전체 문자의 약 60%에만 제공되고, 최종 시각 확정에는 p95 27.74초가 걸린다. 정렬을 자주 실행하는 것만으로 전사·시각·화자를 안정적으로 함께 제공하기 어렵다.

**장점**

- 전체 발화 구간이 닫히기 전에 임시 텍스트와 일부 화자 포함 결과를 제공할 수 있다.

**단점**

- 정렬 모델을 추가로 실행해야 하며, 임시 전사가 바뀔 때마다 정렬과 화자 연결도 갱신해야 한다.
- 정렬 실패가 곧 화자 연결 실패로 이어지고, 조기 출력도 이후 수정될 수 있다.

### 2. Whisper streaming + Nemotron-3 타임스탬프 결합

WhisperStreaming이 생성한 텍스트·단어 시각과 Nemotron 화자 활동을 시간 겹침으로 연결한다.

**단일 회의 성능**

WhisperStreaming의 faster-whisper large-v3 FP16을 사용하고, 2초마다 누적 음성을 다시 추론한다. 연속 두 번의 결과에서 일치한 텍스트를 확정하고, 단어 시각과 겹치는 Nemotron 화자 활동을 연결한다. A10 한 대에서 5분 입력을 처리한 결과, 발화 단위 CER 진단값은 **20.37%**, 단어 종료 추정 시각→텍스트 확정 지연은 **p95 10.60초**였다. 

**동시 처리 성능**

같은 A10 한 대에서 Whisper와 Nemotron 모델을 공유하고, 회의별 상태를 분리해 4개 입력을 처리한다. GPU 호출을 직렬 실행한 구성의 결과다.

| 항목 | 1개 동시 입력 | 4개 동시 입력 |
| --- | ---: | ---: |
| 처리한 음성 길이 | 300초 완료 | 회의별 108~110초에서 중단 |
| 단어 종료 추정→텍스트 확정 지연 p95 | 10.60초 | 회의별 52.22~54.63초 |
| 마지막 ASR 갱신 지연 | — | 회의별 58.00~60.61초 |
| GPU 메모리 표본 최대 | 4,758 MiB | 4,739 MiB |

4개 입력에서는 음성 40초 지점에 이미 처리 지연이 약 19~22초, 60초 지점에는 약 25~27초로 늘어난다. 약 110초 지점에서 60초를 넘는 지연이 발생해 중단한다. 그동안의 ASR·화자분리 호출 시간 합은 약 166.49초로, 110초 동안 들어오는 작업을 같은 속도로 처리하지 못한다.

병목은 GPU 메모리 부족이 아니라 **누적 음성의 반복 추론과 직렬 처리량**이다. 이 구성에서는 단일 회의에서도 확정 지연이 크고, 4개 회의의 동시 입력을 유지하지 못하므로 동시성 요구에 맞지 않는다.

**장점**

- 별도 ForcedAligner 없이 단어 시각을 얻고, 발언 중 텍스트와 화자를 갱신할 수 있다.

**단점**

- 누적 음성을 반복 추론하고 결과의 일치를 기다려 확정하므로, 동시 회의 수가 늘어날수록 처리량과 지연 부담이 커진다.
- 단어 시각과 화자 활동을 사후 연결하고, 아직 화자 활동이 준비되지 않은 결과를 관리해야 한다.

### 3. Nemotron-3 + Qwen3-ASR batch

Nemotron이 연속 입력에서 찾은 화자 구간으로 원본 PCM을 자르고, 닫힌 구간들을 Qwen3-ASR의 비스트리밍 배치 입력으로 전사한다. 입력 구간에 연결된 화자 라벨과 시작·종료 시각을 전사 결과에 함께 붙인다.

**한국어 전사와 구간 종료 후 지연**

기본 `Qwen/Qwen3-ASR-1.7B`에 회의 배경·용어를 문맥으로 제공한 단일 회의 5분 실험이다. 같은 화자가 1초 안에 다시 말하면 구간을 이어 붙이고, 긴 발언은 최대 25초에서 나눈다.

| 항목 | 문맥 없음 | 회의 문맥 제공 |
| --- | ---: | ---: |
| CER 진단값 | 20.13% | **19.00%** |
| 문자 편집 횟수 / 정답 문자 수 | 249 / 1,237 | 235 / 1,237 |
| 화자 구간 종료→전사 출력 지연 p95 | 3.35초 | **3.43초** |
| 처리 구간 수 | 61개 | 61개 |
| 전사 실행 오류 / 빈 전사 | 0 / 0 | 0 / 0 |

화자와 시각이 정해진 음성을 전사하므로, ASR 완료 후 텍스트를 다시 정렬해 화자를 찾을 필요가 없다. 문맥을 제공한 결과에서는 문자 편집 횟수가 14개 줄고, 구간 종료 후 지연은 p95 3.43초로 10초 목표 안에 들어온다. 

**단일 A10에서 10개 회의까지 동시 처리**

동시성 실험에서는 한국어 특화 `TeamUNIVA/qwen3_asr_1.7b_ko`와 Nemotron-3를 한 A10에서 실행하고, 최대 8개 음성 구간을 한 ASR 배치로 처리한다. CPU 4개·RAM 16 GiB, 16kHz mono PCM, 회의별 5분 음성을 100ms 청크로 1배속 전송한다. 하나의 녹음을 회의별로 37초씩 순환 이동해 서로 다른 시점에 발화가 들어오게 구성한다.

| 동시 회의 수 | 정상 완료 | 수신 전사 수 | 구간 종료→수신 p95 | ASR 큐 대기 p95 | ASR 배치 처리 p95 | 입력 종료 후 남은 처리 최대 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 4개 | 4 / 4 | 196개 | 3.90초 | 0.66초 | 1.80초 | 1.69초 |
| 6개 | 6 / 6 | 295개 | 4.20초 | 1.15초 | 1.95초 | 2.39초 |
| 8개 | 8 / 8 | 392개 | 4.32초 | 1.24초 | 1.97초 | 1.99초 |
| **10개** | **10 / 10** | **492개** | **4.76초** | **1.46초** | **1.96초** | **4.29초** |

구간 종료→수신은 재생 기준의 발화 구간 종료 시각부터 로컬 수신 클라이언트에 전사 메시지가 도착하기까지다. 구간 종료 대기, Nemotron 처리, ASR 큐·배치 처리, 결과 전달을 포함한다. ASR 큐와 배치 처리의 p95는 각각 별도로 집계한 값이다.

4개에서 10개로 동시 입력이 늘어도 ASR 배치 처리 p95는 **1.80~1.97초**를 유지하고, 전체 지연 p95는 **3.90→4.76초**로 증가한다. 10개 입력 모두 정상 종료하며, 492개 전사에서 회의 ID·순번·시간 범위·종료 길이 검사 오류는 없다. 10개 단계의 GPU 메모리 표본 최대는 **8,746 MiB**다.

따라서 **확인한 동시 10개까지는 발화 구간 종료 후 p95 10초 목표를 만족하는 구성**이다. 누적 음성을 계속 다시 추론하는 Whisper 경로와 달리, 닫힌 구간을 전사하고 여러 회의의 구간을 배치로 묶는 방식이 동시 처리에 적합하다. 

**장점**

- 화자 구간을 전사의 입력 단위로 사용해 별도 ForcedAligner와 시각 겹침 기반 사후 화자 연결을 줄인다.
- 발화 구간 전체와 회의 문맥을 함께 제공해 한국어 회의 전사에 활용할 수 있다.
- 여러 회의에서 닫힌 구간을 모아 ASR 배치로 처리할 수 있다.

**단점**

- 구간이 닫힌 뒤 전사하므로, 발언 중 임시 텍스트를 계속 제공하는 방식보다 출력 시점이 늦다.
- 화자 구간의 누락·잘못된 경계·화자 오판이 ASR 입력과 전사 결과에 영향을 준다.
- 원본 mono 음성을 자르므로 겹친 화자의 음성이 그대로 포함된다. 화자별 구간을 만드는 것만으로 음원분리가 되지는 않는다.

### 4. E2E 모델들

VibeVoice와 같이 음성에서 화자와 전사를 함께 출력하는 모델을 사용한다. Nemotron 공식 SpeakerTaggedASR 결합 경로도 화자 포함 전사를 직접 얻는 후보로 함께 고려한다.

**한국어 회의 성능**

같은 한국어 회의 첫 5분의 전사 결과를 비교한다. VibeVoice는 저장된 전체 출력 텍스트, Nemotron 공식 결합과 Qwen batch는 정답 발언과 시간상 겹치는 출력 구간을 채점한다.

| 후보                                                | CER 진단값    | 문자 편집 횟수 / 정답 문자 수 | 실제 출력에서 드러난 문제                          |
| ------------------------------------------------- | ----------: | ------------------: | --------------------------------------- |
| VibeVoice-ASR-Streaming-1.5B                      | **70.17%** | 868 / 1,237        | 한국어 입력 초반에 영어 문장을 출력하고, 이후 발언·용어도 크게 왜곡 |
| Nemotron-3.5 ASR + Nemotron-3 공식 SpeakerTaggedASR | **28.94%** | 358 / 1,237        | 화자는 붙지만 기술 용어와 일반 발언의 인식 오류가 남음         |

**장점**

- 화자와 전사를 함께 출력해 별도 연결 로직을 줄일 수 있다.

**단점**

- 한국어 회의 전사 품질이 요구에 미치지 못해 제외한다.

---

## Decision

**Nemotron-3-Diarization으로 화자 구간을 만들고, 해당 구간의 원본 음성을 Qwen3-ASR에 배치 입력해 전사·구간 시각·화자 라벨을 함께 제공한다.**

한국어 회의 전사 품질, 발화 종료 후 p95 10초 이내의 지연, 동시 처리, 화자분리와 전사의 결합을 종합해 이 구조를 선택한다. 발언 중 임시 텍스트를 계속 갱신하는 대신, 화자 구간이 닫히면 해당 음성을 전사해 시각·화자와 함께 전달한다.

선택을 가르는 차이는 다음과 같다.

- **ForcedAligner 경로:** 전사 자체는 빠르지만 정렬 실패 때문에 시각·화자를 연결하지 못하는 부분이 크다. 최종 화자 연결 범위는 출력 문자의 76.48%다.
- **Whisper 경로:** 별도 정렬 없이 시각을 얻지만, 시험한 직렬 실행 구성에서는 동시 4개 입력에서 지연이 누적돼 중단한다.
- **E2E 후보:** 화자 포함 출력의 편의보다 한국어 전사의 인식 오류가 크다.
- **화자 구간별 Qwen batch:** 별도 정렬 단계를 없애고, 단일 입력 CER 진단값 19.00%와 동시 10개 입력의 구간 종료→수신 p95 4.76초를 근거로 선택한다.

화자 구간을 전사의 입력 단위로 삼아 별도 정렬과 사후 화자 연결을 줄인다. 회의별 화자 상태를 유지하고, 여러 회의에서 닫힌 구간을 ASR 배치로 처리한다. 긴 발언은 구간 길이 상한에서 나누어 출력 대기를 제한한다.

출력 시각은 Nemotron 화자 구간의 경계로 정의한다. 단어별 정렬 시각과 참가자 실명 연결은 이 결정에 포함하지 않는다.

2026-10-28 분할 정책 변경: 동일 mono PCM을 여러 화자의 입력으로 중복 전사하지 않도록, 프레임마다 활동 확률이 가장 높은 화자 한 명만 선택한다. 최고 확률이 0.5 이하이면 무음으로 처리한다. 다른 화자가 선택되면 이전 구간을 닫으며, 같은 화자의 1초 이내 발언 병합은 사이에 무음만 있을 때 허용한다. 최대 25초 분할과 500ms 미만 구간 생략은 유지한다. 이 정책은 ASR 입력의 시간 중복을 막지만, 실제로 겹친 음성을 분리하거나 모든 화자의 발언 복원을 보장하지 않는다. 위 실험 수치는 변경 이전 정책의 결과다.

2026-10-28 화자 전환 보류: 다른 화자가 선택되어도 이전 구간을 즉시 닫지 않는다. 새 화자의 구간(짧은 무음 포함)이 500ms 이상 이어지면 전환을 확정하고 이전 구간을 마지막 활동 시점에서 닫는다. 그 전에 이전 화자가 자신의 마지막 활동 후 1초 이내 돌아오면, 사이의 짧은 화자 구간은 따로 전사하지 않고 앞뒤 구간과 함께 하나의 ASR 입력으로 처리한다(예: A 0~1초 → B 1~1.3초 → A 1.3~3초는 A 0~3초). 이전 화자가 1초 안에 돌아오지 않으면 기존 무음 규칙대로 닫는다. ASR 큐에 넣은 구간을 사후에 병합하지 않으므로 같은 PCM이 중복 전달되지 않으며, 25초 분할과 EOF 처리는 유지한다. 실제 화자 전환마다 이전 구간의 확정이 최대 500ms 늦어지고, 500ms 미만의 실제 짧은 발언(추임새 등)은 앞뒤 화자의 텍스트에 섞여 그 화자의 발언으로 표시될 수 있다.

## Consequences

### Positive

- 전사·시각·화자 라벨을 동일한 입력 구간에 연결해 제공하고, 별도 정렬 모델과 반복적인 사후 연결 처리를 줄인다.
- 회의 문맥을 구간별 ASR 입력에 제공하고, 여러 회의의 닫힌 구간을 공유 ASR 배치로 처리할 수 있다.
- 닫힌 구간을 한 번 전사하므로 누적 음성의 반복 추론을 줄일 수 있다.

### Negative

- 구간 종료 대기와 긴 발언의 분할을 감수한다. 단어별 시각이나 발언 중 연속적인 임시 전사가 필요하면 별도 방식을 검토해야 한다.
- 화자분리의 경계·화자 오판이 전사 입력에 영향을 주며, 겹친 음성은 원본 구간에 함께 포함된다.

---

## Reconsideration Conditions

- 운영 대상 동시 회의 수에서 발화 종료→결과 수신 p95가 10초를 반복해서 넘거나 처리 대기열이 지속해서 증가하면, 배치 정책·수용량·모델 구성을 재검토한다.
- 독립된 한국어 회의 평가에서 구간 누락, 짧은 발언 손실, 겹친 발화의 전사·화자 오류가 주요 품질 문제로 확인되면, 분할 정책과 음원분리·다른 ASR 결합 방식을 비교한다.
- 단어별 시각 또는 발언 중 계속 갱신되는 전사가 제품 요구가 되면, 스트리밍 ASR·정렬·화자 포함 전사 모델을 다시 비교한다.
