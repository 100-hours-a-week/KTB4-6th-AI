# ADR-0012: 실시간 STT를 외부 API에서 Modal 직접 서빙으로 전환한다

## Status

Accepted

---

## Context

Meety는 [ADR-0005](0005-stt-provider-speechmatics.md)에 따라 Speechmatics로 한국어 회의를 실시간 전사한다. 외부 API 이용 불가로 전사가 중단된 경험을 계기로, 특정 STT 공급자에 대한 의존을 줄이고 모델과 추론 방식을 직접 제어하려 한다. 한국어·회의 용어에 맞게 모델을 선택하고 개선할 수 있는 것도 중요하다.

클라우드 V2 성장 시나리오에 대응하려면 동시 회의 증가에 맞춰 전사 처리 용량을 늘릴 수 있어야 한다. 충분한 GPU를 확보할 수 있다고 가정하고, worker 증설로 해당 규모를 수용하는 구조를 설계한다. 

이 ADR은 전사의 기본 공급 경로를 결정하며 ADR-0005를 대체한다. 

---

## Decision Drivers

- **STT 공급자에 대한 의존을 줄일 수 있는가?** 공급자의 이용 제한이나 API 문제에 대응할 선택권을 확보한다.
- **모델과 추론을 직접 제어할 수 있는가?** 한국어·회의 용어에 맞는 모델 선택과 추론 설정 개선을 팀이 수행한다.
- **V2 규모에 맞춰 확장할 수 있는가?** 공급자의 세션 한도 대신 필요한 GPU와 worker 수를 산정하고 증설한다.
- **예상 사용량에서 비용이 합리적인가?** 음성 사용료와 GPU의 준비·유휴 시간을 포함한 운영 비용을 비교한다.

---

## Considered Options

### A. Speechmatics를 유지한다

실시간 AI가 회의 음성을 Speechmatics로 보내고 확정 전사를 받는다.

**장점**

- 기존 전사 경로를 유지하며 모델 운영과 추론 용량 관리를 공급자에게 맡길 수 있다.
- GPU 모델의 준비·메모리·추론 실행을 직접 관리할 필요가 적다.

**단점**

- 공급자의 이용 가능 여부와 세션 한도에 영향을 받는다.
- 모델과 추론 내부 동작을 직접 변경하기 어렵다.

### B. Modal에서 모델을 직접 서빙한다

실시간 AI가 디코딩한 음성을 Modal GPU worker로 보내고, 전사 결과를 Backend에 전달한다.

**장점**

- 모델과 추론 설정을 직접 선택하고 개선할 수 있다.
- 회의 수에 맞춰 GPU worker를 늘리는 방식으로 용량을 계획할 수 있다.
- 여러 회의가 GPU를 공유해 자원 사용률을 높일 수 있다.

**단점**

- 모델 운영, 처리 지연, 품질과 용량 관리를 팀이 맡는다.
- Modal 장애와 GPU 자원 확보 문제에 대한 대응이 필요하다.
- 사용량이 적으면 GPU 준비·유휴 비용의 비중이 커진다.

---

## Decision

**Modal에서 모델을 직접 서빙하는 방식을 기본 전사 경로로 채택한다.**

외부 API 유지보다 운영 책임은 늘지만, 모델과 추론을 직접 제어하고 V2 규모에 맞춰 처리 용량을 설계할 수 있다는 점을 우선한다. 실시간 AI의 디코딩과 Backend 중계 역할은 유지한다.

Speechmatics는 후속 fallback 후보로 남긴다. 자동 전환의 장애 판정과 음성 재전송·중복 방지 규칙은 별도로 결정하며, 외부 STT 전송을 허용한 회의에만 적용한다.

---

## Consequences

### Positive

- 한국어 모델과 회의 문맥을 활용하는 전사 방식을 직접 개선할 수 있다.
- 외부 STT API의 세션 한도와 별개로 GPU worker 증설을 계획할 수 있다.
- 모델 운영 설정과 비용 구조를 팀이 관리한다.

### Negative

- 전사 품질·지연·모델 운영에 대한 책임이 팀으로 이동한다.
- Modal 의존성은 남으며, 자동 fallback을 도입하기 전에는 Modal 장애를 우회할 전사 경로가 없다.

---

## Reconsideration Conditions

- 모델 운영 부담이나 총비용이 외부 API 유지보다 커질 때.
- 한국어 전사 품질 또는 결과 지연이 서비스 요구를 충족하지 못할 때.
- Modal의 자원 확보와 운영 제약이 서비스 확장을 막을 때.
